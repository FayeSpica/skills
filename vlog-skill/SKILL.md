# Vlog 剪辑与审美

把旅行经历剪成有起伏、有人物和现场感、值得重看的纪念片。以下审美默认来自用户多轮修改；当前明确要求优先。具体地点、歌曲、时码和输出规格均按项目决定。

## 先确定本轮范围

先按本轮需要读取已有时间线、最新剧本、选片索引和纠正。明确是重剪、局部修改、诊断、音乐试听、候选图整理，还是只做封面。「先试试」「我听一下」交付相应小样或试听；「暂不重剪」是范围限制，若只要求诊断，就交付原因、证据和修复建议，不自动生成新片。

将要求分为三类并保留在项目计划中：用户明确要求、可调整的审美默认、实现参数。新选择可以覆盖旧排除中的具体项目；例如用户后来点名某段航拍，应保留这个例外。封面改地名或删日期，只作用于封面，除非用户同时要求改影片。

继续新疆《秋日来信》项目时，读取 [新疆案例](references/xinjiang-case.md)；其他作品无需加载其曲目与时码。

## 审美默认

| 方面 | 剪辑判断 |
|---|---|
| 开场 | 第一眼给最美、最有辨识度的景，按音乐组织短组镜头。普通山路、赶路和车内画面后置；需要车内到车外的过渡时利落完成。 |
| 镜头价值 | 每一镜带来新动作、景别、空间关系或情绪。变化小、信息重复的镜头剪短、移除或换角度；人物完整动作和有意停留不按统一短镜时长硬切。 |
| 中段 | 先按地点、人物动作和行程分组，再用乐句建立快慢。风景、同伴、活动细节和照片交替，避免长时间同类空镜，也避免每镜长度和音乐关系都散乱。 |
| 音乐 | 切镜能听出与音乐的关系，在强拍、乐句和情绪转折上落点。节奏检测提供候选，不等于每个鼓点必须切；保留动作完成和声音的呼吸。 |
| 报幕 | 片名与章节字居中，参考用户给图的字形、方向和留白。文字底色浅淡半透明；优先把字叠在合适的风景处，避开人脸、白招牌和复杂高亮。黑幕和报幕短促，文字可读后尽快回到画面。 |
| 照片 | 承担“瞬间定格”，优先保留原构图和静止感。照片入画同步一个真实相机快门；轻微闪白或黑边定格按当前风格选用，强度克制。 |
| 尾声 | 用新角度、新动作或正文未用的照片完成情绪收束；“回闪”可以回到同一旅程，但避免机械重播正文。配乐高潮和尾音与尾声内容匹配。 |
| 导航 | 用户需要进度和位置时，做底部章节进度条，当前地点清晰、其他章节弱化；位置边界跟随实际时间线，留出主体与字幕空间。 |
| 封面 | 延续正片报幕的真实背景和标题气质，标注 Vlog；缩小后仍能读清。分别构图与导出所需比例，文案依用户当轮选择。 |

上述默认可以被作品需要覆盖。不要把本项目的禁车、排除某一天、特定字体数值或歌曲当作所有 Vlog 的规则。

## 选片与剧本

1. **建立素材索引。** 探测原视频与音频，区分正片、代理、视频关键帧、独立照片和配乐版本。索引记录源文件、时长、尺寸、帧率、位深、色彩标记、音轨与拍摄信息。代理用于选片，成片回原素材。
2. **看连续动作。** 联系表用于筛选；入选视频检查起、中、尾和实际动作窗口，剔除对焦失败、甩镜、无意义停留与弱重复。无人机片段看机位和空间变化，照片看人物表情与构图，不能仅凭文件名或一张漂亮关键帧决定片段长度。
3. **落实用户选片。** 将勾选文件名映射回原素材和时间点。视频关键帧回到连续视频，独立照片回原图；为每项记录采用位置、合并到哪一镜，或未用原因。允许有依据地合并相似项，不悄悄丢掉用户选择。
4. **重新分组。** 新增无人机、照片或音乐后，审视整段主线，优先替换弱镜，按人物行动与地点形成段落。片长随有效内容决定；3–15 分钟只是此次旅行任务的范围，下一项目以用户要求为准。
5. **写可执行时间线。** 每镜记录源文件与源入出点、成片入点、长度、章节、画面目的、原声处理；文字、照片音效、音乐独立记事件。明显改动同步更新剧本和镜头表。

采用 FFmpeg 或脚本建立时间线、混音、缓存、导出或验证时，读取 [媒体技术与验证](references/media-pipeline.md)，尤其是帧边界、精确 PCM 和最终文件核对。

## 配乐与声音

- 为每个参考注明角色：可用音乐、视觉参考、音效参考。参考视频里带旁白，不代表其音轨可以进入成片；用户指定的干净音源优先。现场人声另行判断，保留有价值的对话、笑声、脚步和环境声。
- 按段落情绪选音乐的源窗口，分析真实音源的起音、强拍和乐句。需要音乐在某地点结束时，画面与混音一起调整；换器乐版、翻唱版或另一剪辑版后重校准偏移与速度。
- 把关键切点落到可复核的帧上，听看连贯的前后文。中段出现混乱时，检查是否混用了不同节拍尺度、重复弱景或过密照片，而不是只整体平移 BGM。
- 相机音效先用用户指定的实录文件，裁到干净机械声。试听请求直接提供音频小样；用户尚未选定时不要宣称与某博主同款。快门峰值、闪白和照片首帧一起对齐。
- 在有现场人声处调整 BGM 电平或适度 ducking，检查音乐接缝和尾音。记录最终实际响度与峰值，不把目标参数当测量结果。

## 画面、报幕和封面

先在真实画面上检查文字大小、留白、对比和裁切。浅底读不清时，优先调整出字时机、合适画面或轻微阴影，不直接加深为厚重黑块。短黑幕应为音乐服务；跨镜标题使用连续时间，避免突然重启淡入。字体尺寸和持续时间随分辨率、字数和场景确定。

新建封面时，从原视频取代表帧，参考正片报幕进行排版。修改既有封面时，优先沿用母版、背景与构图，只调整用户要求的内容。只制作用户要求的比例；同时要 4:3 和 16:9 时分别检查主体、文字安全边距和缩略图可读性。日期、年份、地点与 Vlog 字样按封面文案单独管理。生成式编辑可能改变背景细节，使用时对照原帧核查并说明方式，不能声称生成图与原帧像素一致。遵循当前可用图像工具的要求。

用原素材完成正式输出，保留比例、色彩和细节。导出分辨率、编码与码率要适合来源和设备；原生 1080p、8 位照片或压缩原片的局限如实说明。保留可回退的旧成片，避免多次拿导出的片子继续有损压缩。

## 完成标准

仅应用本轮相关项目：重剪和局部改版检查受影响的成片；诊断交付证据与修复建议；试听交付音频小样；封面只检查各比例图片。不要为了满足整片清单扩大任务。

- **内容**：用户明确选片有去向；排除项及其例外正确；尾声按当前要求去重；正文、封面和元数据的文案范围分别核对。
- **审美**：实际画面核对开场、章节出字、照片、转场与尾声；判断动作和景别变化。能连续试听时检查段落节奏、人声、音乐接缝和尾音；无法试听应明确验证边界。
- **技术**：核对最终成片而非仅中间文件，包括解码、音画起点与时长、主要音乐窗口、全部效果入点、图层边界和画质代表样本。每次改版重验受影响项。
- **交付**：提供可播放的最终文件与准确时长，重要改动附更新后的剧本或时间线；封面提供各比例独立文件。报告区分程序检查、代表帧目视检查和连续试听，不用“导出成功”代替审美判断。
